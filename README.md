## 🚀 Overview
Titan is an agentic RAG platform designed to audit SEC filings. Unlike legacy tools, it fetches live XBRL data directly from EDGAR and uses AI to detect "Risk Shift" between filing years.

## 🛠️ Tech Stack
- **Engine:** edgartools (SEC API)
- **Intelligence:** OpenAI GPT-4o
- **Frontend:** Streamlit
